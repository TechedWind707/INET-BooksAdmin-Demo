Your current computed property is CoverImageUrl in BooksAdmin/Models/Book.cs. It is marked [NotMapped], meaning SQL never stores it. For an uploaded cover, you need a separate persisted URL property.

Before coding: prove storage is reachable

Azurite is already running in Docker as Azurite1. Its Blob port is mapped from Docker's 10000 to your computer's 10006.

Do not use UseDevelopmentStorage=true here.
That shortcut expects host port 10000, but your container is exposed on 10006.

Connection string shape

Use the standard Azurite account name, default account key, and this endpoint:

BlobEndpoint=http://127.0.0.1:10006/devstoreaccount1;

Add that endpoint to the Azure storage connection string. Keep the whole connection string in user secrets or appsettings.Development.json, never the production appsettings.json.

Reason: your app connects from the Windows host, not from inside Docker. It must use the host-side port 10006.

In Views/Books/Create.cshtml, change the form to multipart form data. Add a file input named exactly the same as the controller's file parameter. Restrict the picker to image MIME types if your instructor expects it.

Name matching rule: the input name and controller file-parameter name must match exactly. If they differ, ASP.NET gives you null.

Add an IFormFile parameter. When the normal model is valid and a non-empty file was supplied: generate a safe unique blob name, upload through your service, place the returned URL in the persisted Book property, then save the Book.

Do not use the browser's original filename as the final blob name. Two students could upload cover.jpg; a generated unique name prevents one upload from overwriting another.

Upload first, assign the returned URL to the book, then save the book. Otherwise SQL can save a book before it knows where its image lives.

Question: Why should the database store the blob URL instead of the raw image file?
SQL keeps a small pointer that identifies the image. Azurite is built to store file bytes. This keeps each system doing one job and lets the views load the image using its URL.
